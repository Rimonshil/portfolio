# Rimon Shil — DevOps Portfolio

Personal portfolio website for Rimon Shil, DevOps Engineer with 4+ years of experience in AWS, Kubernetes, CI/CD, and DevSecOps.

## 🚀 Live Site

Hosted on GitHub Pages: `https://<your-username>.github.io/<repo-name>`

## 🛠 Stack

- Pure HTML, CSS, JavaScript — zero dependencies, zero build step
- Google Fonts (Inter + JetBrains Mono)
- Fully responsive, mobile-first layout
- Smooth scroll animations with IntersectionObserver

## 📁 Structure

```
portfolio/
├── index.html    # Main HTML
├── style.css     # All styles (dark theme, responsive)
├── main.js       # Typed effect, scroll animations, nav
└── README.md
```

## 🖥 Deploy to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch → main → / (root)**
4. Your site will be live at `https://<username>.github.io/<repo>`

## ✏️ Customise

- Update contact links in `index.html` (GitHub URL, LinkedIn)
- Swap in your own photo by adding an `<img>` tag in the hero section
- Add project GitHub links by updating the project cards with `<a href="...">` buttons
